# 合票 7.2

下载并运行 `PayMerge-PDF.exe`，不需要其他配套文件。

1. 打开“设置”，填写姓名、组别，选择保存位置；留空使用程序目录。
2. 点击“添加”或拖入一份 PDF 和两张截图，截图依次为购买、支付记录。
3. 核对票号和金额，点击“合并 PDF”。字段缺失或冲突时，补填并勾选“已核对原件”。

图片型 PDF 需要人工填写，不包含 OCR。多页发票保留全部页面，最后一张与截图共页。文件名为“姓名_组别_金额_票号后四位.pdf”。重名时，“是”覆盖，“否”加序号，“取消”停止。失败会保留输入。

## 设置和缓存

程序旁无需 `config.json`、DLL 或许可目录。设置保存在 `%LOCALAPPDATA%\PayMerge-PDF`；PDF 引擎从 EXE 内解压、校验到同一用户目录的运行缓存。字体和许可内嵌，“设置 → 许可”可查看许可。

第一次启动可读取 EXE 旁的旧 `config.json` 并迁移，旧文件保留。绝对输出路径失效时仍按相对于 EXE 目录的路径处理。

## 更新

点击“更新”查看版本、下载并“重启升级”。程序也会在启动时及运行期间每 6 小时检查正式 GitHub Releases。更新只替换当前 EXE；设置和已生成 PDF 保留。替换或启动校验失败时恢复旧版本。有待处理材料时需先输出或清空。网络失败不影响合并。

7.1 及更早版本首次需要手动下载单文件版，7.2 起可直接在线升级。更新时程序目录需可写，临时升级进程及文件会在完成后清理。
