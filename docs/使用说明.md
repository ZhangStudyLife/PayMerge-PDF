# PayMerge-PDF 7.1 使用说明

解压整个发布包，双击 `ASC_InvoiceMergeTool.exe`。保留旁边的 `PayMergeUpdater.exe`、`pdfium.dll` 和 `licenses` 目录，无需安装 Python 或 Rust。

首次运行填写姓名、组别，按需选择输出目录；留空则保存到程序所在目录。设置写入程序旁的 `config.json`，请使用有写入权限的文件夹。侧栏“使用者与保存位置”可以重新设置。

1. 选择或拖入一份发票 PDF。
2. 依次添加购买记录截图、支付记录截图，三张材料卡片显示文件对应的位置。
3. 核对发票号码、价税合计、开票日期与销售方。金额和完整票号可以修改。
4. 点击“一键输出 PDF”，文件名为“姓名_组别_金额_票号后四位.pdf”。

同名文件存在时，“是”覆盖，“否”添加序号，“取消”停止输出。合并失败会保留输入文件，修正后可以重试。更换发票或清除材料时，旧识别结果和人工填写值同时清除。

有文字层的电子发票自动提取字段。图片型 PDF 仍可合成，但需手工填写金额、完整票号，并勾选已核对票面。关键字段冲突时同样需要核对确认。票据在本机处理，不上传至在线识别服务。

单页发票占 A4 上半页，购买记录和支付记录分别位于左下、右下。多页发票按原顺序保留，最后一张发票与两张截图共用最后一页；按 300 DPI、10 mm 页边距合成。

## 更新程序

程序启动时和持续运行期间每 6 小时自动检查 [GitHub Releases](https://github.com/ZhangStudyLife/PayMerge-PDF/releases)。侧栏的“检查更新”可以手动检查；发现新版时显示“有新版本”。

打开更新窗口，查看说明，点击“下载更新”。下载与 SHA256 校验完成后，点击“重启并升级”。还有待处理材料时，请先完成输出或清除。升级程序等待主程序退出、替换文件并校验新版；失败会尝试恢复旧程序，姓名、组别、输出目录和已生成的 PDF 均保留。网络不可用时仍可正常处理票据。

更新跟踪本仓库正式发布的 Windows x64 ZIP，不会因普通 Git 提交而升级。更新包和暂存文件都放在程序目录内，程序目录需有写入权限。

7.0 及更早版本首次升级需要手动下载完整 ZIP，并将原 `config.json` 复制到新程序旁。保留旧版配置中的 `name`、`group`、`output_path_absolute`、`output_path_relative` 字段；绝对输出目录失效时会尝试相对于程序目录的路径。
