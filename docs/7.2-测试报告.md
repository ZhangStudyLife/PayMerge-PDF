# 合票 7.2 测试报告

日期：2026-11-20。服务器构建、Windows 原生运行与离屏渲染验收，全部测试未使用 Computer Use 或系统鼠标键盘注入。

## 交付与界面

正式分发目录只包含 `PayMerge-PDF.exe`，共 1 个文件。PDFium、中文字体及第三方许可均内嵌，不需要旁置 DLL、升级器、配置或许可目录。运行时 PDFium 解压并校验到用户缓存，配置写入用户数据目录；单文件指分发物及程序目录，不代表程序不使用运行缓存。

界面采用宣纸色、墨黑、少量朱砂色和毛笔字标题，去掉旧侧栏、步骤编号、口号、重复状态和说明段落。常驻内容限于材料、票号、金额、输出与必要操作。字体子集来源、重命名与哈希记录在 `assets/ink-font-source.json`，许可可在程序“设置 → 许可”内查看。

升级基线使用带有测试标记的有效 7.2 PE 副本，确保替换及回滚前后文件哈希不同且可逐字节核对；未宣称 7.1 的旧 ZIP 协议可以直接安装 EXE 更新。7.1 及以前首次切换需手动下载，7.2 起使用单 EXE 更新协议。

Windows 验收使用隔离的 `PAYMERGE_DATA_DIR`，不写实际用户配置。原生文件选择对话框、系统拖放和弹窗按钮没有自动点击；对应业务状态入口已覆盖测试。新版本仍保留金额与票号人工核对及缺失/冲突确认门槛。
